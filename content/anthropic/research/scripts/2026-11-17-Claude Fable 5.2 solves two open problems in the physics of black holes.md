先把背景铺开。现代物理学有两根大柱子，一根是广义相对论，管的是非常大的东西，比如恒星、星系、时空弯曲；另一根是量子力学，管的是非常小的东西，比如原子、电子、粒子。两支理论在各自范围内都准得惊人，但它们在数学上不兼容。物理学家一直想找到一个统一两者的理论，也就是量子引力。黑洞是天然的试验场，因为它把极大的质量塞进极小的空间，广义相对论和量子力学在这里都必须出场。你可能会问，为什么研究量子引力要绕到模型宇宙里去？原因很现实：真实宇宙太复杂，四维时空加上量子场论，很多计算根本下不了手。物理学家于是构造一些更简单的模型宇宙，在模型里把问题算清楚，再回头找启发。

文章里最重要的工具叫全息对偶。真实宇宙有三个空间维度加一个时间维度，相对论把它们合成四维时空。全息对偶的基本想法是，某些理论宇宙可以有两种描述方式：一种是有引力、有完整时空的宇宙；另一种是没有引力、纯量子的理论，写在宇宙的外边界上。就像一张二维全息片能编码三维图像，一个多一维的引力宇宙，可以用少一维的量子理论来完整描述。比如四维空间的引力，可以对应三维空间里没有引力的量子理论。这样做的价值在于，引力侧很难算的问题，可以翻译成量子侧的问题，而量子侧有时候反而能算。

第一个问题要从一九八三年的霍金和佩奇说起。他们研究一种叫反德西特时空的模型宇宙。你可以想象自己站在一个巨大的碗里，无论怎么用力扔东西，东西总会滚回你身边。我们的宇宙不是这样，我们的宇宙在加速膨胀，因为真空能量是正的，也就是宇宙学常数是正的。反德西特时空的宇宙学常数是负的，所以一切都被拉回去，而且这个碗还能把热量留在里面，让系统保持一个稳定温度。霍金和佩奇问的是：把这个碗加热，会发生什么？低温下，碗里是一团普通粒子气体，包括引力子；温度高到某个点，碗里会形成黑洞。更关键的是，这个切换不是慢慢过渡，而是突然的相变，像水到一百摄氏度突然沸腾。这个温度后来就叫霍金—佩奇温度。

但霍金和佩奇的计算依赖广义相对论，而广义相对论只在宇宙尺度远大于普朗克尺度时有效。当模型宇宙缩小到接近普朗克尺度，时空本身失去确定形状，变得模糊，引力侧的计算就不知道怎么做了。可是在全息对偶的量子侧，同样的情境原则上可以算。一九九九年，物理学家发现量子侧也存在一个相变，但他们不知道这个相变是像霍金—佩奇那样突然跳变，还是平滑过渡。二〇〇三年，一组物理学家把能判定这个问题的计算框架写了出来，但计算极其复杂，一直没有完成。文章说，Claude 把它做完了。

这里要先解释一个很核心的物理思想，叫历史求和。想象你从纽约宾夕法尼亚车站去高线公园西三十街和第十大道的入口，有两条差不多好的路线，你可以先往西再往南，也可以先往南再往西。现实中你只能选一条。但在量子世界，一个粒子可以同时走两条路线。最著名的例子是双缝实验：粒子一个一个发射，穿过两条狭缝，最后在屏幕上形成条纹，好像每个粒子都同时穿过了两条缝。为了预测量子粒子的行为，物理学家要把粒子所有可能走的路径加起来，这叫可能历史求和。不是每个历史权重一样，有的贡献大，有的贡献小。这个描述听起来很奢侈，但它是物理学最成功的想法之一。

把历史求和用到引力上，问题就变得更大。爱因斯坦告诉我们，引力是时空弯曲的表现，有质量的物体会让周围时空弯曲。所以在量子引力里，要求和的不只是粒子路径，而是时空本身的形状。我们要把宇宙可能采取的所有时空形状都加起来。没有人知道该怎么做，现代量子引力研究很大一部分就是在想办法处理这个求和。霍金和佩奇找到的，是一个求和足够简单、但仍然有意思的案例。在他们的反德西特碗里，任意温度下有两个历史贡献最大：一个是碗里充满粒子气体，包括引力子；另一个是碗里有一个黑洞。哪个贡献更大，哪个就相当于我们观察到的宇宙。低温下气体历史赢，高温下黑洞历史赢，中间在霍金—佩奇温度发生突然切换。这是很少见的案例，我们能看见两种完全不同的时空形状在历史求和中竞争，并能判断谁赢。

接下来全息原理登场。二十世纪七十年代，贝肯斯坦和霍金发现，黑洞能容纳的信息量正比于它的表面积，而不是体积。普通物质不是这样，普通物质每个体积单元大概装同样多的信息，体积越大信息越多。黑洞的信息却长在表面上。九十年代初，特霍夫特和萨斯坎德提出，这个想法可能对引力普遍成立：一个空间区域里的全部信息，可以由它边界上的信息完整描述。一九九七年，马尔达西纳把这个想法形式化：反德西特碗内部的引力，等价于碗边缘上没有引力的普通量子粒子理论。这就是文章开头说的对偶的两侧，引力侧和量子侧，它们是描述同一个底层现实的两种语言。

Claude 研究的这个案例里，边缘上的量子理论叫 N 等于四的超对称杨米尔斯理论。它和描述真实宇宙粒子相互作用的理论有关系，但带有额外对称性，所以物理学家更容易处理。既然引力侧预测有两种历史竞争，一个自然的问题就是：量子侧的 N 等于四超对称杨米尔斯理论，会不会显示同样的相变？目前物理学家只能在粒子之间几乎不相互作用时详细分析这个理论，这个条件叫弱耦合。弱耦合正好是霍金—佩奇引力计算有效范围的另一端。量子侧的弱耦合，对应引力侧那个又小又模糊的宇宙。所以没有人保证霍金—佩奇的结论在弱耦合下还成立。

结果很奇妙，它确实成立。一九九九年桑德博里，以及后来阿哈罗尼、马萨诺、明瓦拉、帕帕多迪马斯和范拉姆斯东克等人证明，即使在弱耦合下，边缘上的理论随温度升高也会经历一个相变。这是碗里气体变黑洞的对应物。但当时仍然不知道这个相变是突然跳变，还是平滑渐变。当粒子几乎不相互作用时，物理学家只能一步一步算。他们先从一个粒子完全不相互作用的简化理论开始，然后一层一层加修正，每一层更精确也更难算。这些层叫圈。二〇〇三年，阿哈罗尼和他的同事意识到，相变到底是突然跳变还是渐变，取决于一个只出现在第三圈的数。算这个数涉及成千上万个图，也就是费曼图之类的计算项，手算根本不可能。二〇〇五年，同一个团队算了一个更简单的姐妹理论，发现是突然跳变。但 N 等于四超对称杨米尔斯这个版本，计算规模是那个姐妹理论的十倍以上，一直没人完成。

这里不光是计算量大。还有一个概念上的障碍：如果天真地把计算的所有部分加起来，会得到无穷大，必须非常小心地把这些无穷大处理掉，才能提取出有意义的有限结果。Claude 的做法是运行一个小型研究组，成员都是它自己的副本。几乎每一个计算片段都由两个智能体独立完成，互相核对；有些部分还能和文献里的已知结果对比。最后它得到的结果是：温度升高时出现突然跳变，和霍金—佩奇用时空历史求和得到的结果完全对应。画面变得很简单：这个相变在弱耦合和强耦合两端都是突变的，也就是在引力描述里模糊的一端和平滑的一端都是突变的。最自然的可能性是，中间所有地方都保持突变。文章说这是一个漂亮的结果，因为它表明引力侧的历史求和计算，和完全没有引力的普通量子理论，在定性行为上对上了。

当然，开放问题还在。突变相变有一个有趣特征：输掉竞争的那一方可以存活一段时间。比如水可以超过一百摄氏度还不沸腾，也就是过热。文章提醒，别真的把极纯的水放进微波炉做这个实验，很危险。这里也类似，在霍金—佩奇温度以上，热气体可以以过热状态存活很久，但再高到某个温度就活不下去了，这是另一个相变，叫哈格多恩相变，是弦论的一个特征信号。引力侧的这个相变有很多有趣性质，值得仔细检查它们在 N 等于四超对称杨米尔斯理论里是否也出现。另一个开放问题是其他时空历史。霍金和佩奇主要考虑三种：充满气体、包含大黑洞、包含一个永远不会主导求和的小黑洞。原则上还有更多历史。据目前所知，它们都不会主导。但如果改变初始条件，比如让宇宙旋转，或者固定能量、固定电荷，某些历史就可能接管。到底哪些历史在什么条件下赢，是未来的问题。

第二个问题换了一个更简单的模型宇宙：三维引力，也就是两个空间维度加一个时间维度。这个模型比真实世界简单得多，但仍然有黑洞和许多类似的谜团，是研究时空历史求和的好实验室，也是测试“时空不是基本 ingredients，而是从更深层东西涌现出来”这一想法的好地方。在广义相对论里，黑洞看起来光滑；但在量子引力里，如果放大到普朗克尺度，也就是大约十的负三十五次方米，量子效应对引力不可忽略，黑洞应该由大量微小的基本构建块组成。物理学家相信我们的四维宇宙也是这样，但三维版本更容易用全息对偶分析。

Claude 的第二个结果建立在自举法上。自举法是一个反直觉的策略：它不直接求解一个理论，而是通过证明某些理论自相矛盾来排除它们。对三维引力来说，直接求解甚至不可能，因为没有人知道怎么精确定义这个理论。物理学家于是扫描所有可能的量子理论，一个一个排除。奇妙的是，在很多情况下，相对论和量子力学的要求非常苛刻、非常精细地平衡，最后只剩下一个理论，或者很少几个理论，行为也被精确确定。二〇一二年，自举法被用来求解三维临界伊辛模型，这是一个简单磁性模型，也描述水在液态和气态无法区分那个点的行为。从那以后，自举法被用到很多量子系统。

二〇〇九年，西梅恩·海勒曼提出模自举法，把自举法用到三维引力上。目标是要排除三维时空中自相矛盾的量子引力理论。物理学家希望把它和其他自举方法结合，最终排除所有不一致的理论，剩下什么就是什么。可能一个都不剩，可能只剩一个，可能剩下一族。不管哪种结果都有意思，因为它能帮助理解这个简化宇宙在普朗克尺度下时空长什么样，也能给我们的宇宙提供线索。

模自举法怎么工作？三维反德西特引力有一个量叫中心荷，记作 c，粗略地说，它数的是宇宙由多少个微观构建块组成。当广义相对论成立时，c 很大，因为大黑洞包含大量构建块。第二个量是 M 一，也就是最轻黑洞的质量。要跑自举法，物理学家扫描所有可能的 c 和 M 一，寻找不一致。为了理解这个搜索，要回到时空历史求和。在三维引力里，就是要把不同的三维时空形状加起来。形状可以简单像球，也可以复杂像甜甜圈和双孔甜甜圈。时空是形状的内部，像甜甜圈里的面团；表面则像碗的边缘，是量子理论“写”的地方，少一维。

模自举法从一个普通单孔甜甜圈形状开始，也就是环面。这个形状有两种解释，取决于我们把哪个方向叫时间、哪个方向叫空间。第一种解释里，绕着孔的长圈是时间，绕着管子的短圈是空间；第二种解释里，两个圈互换，长圈是空间，短圈是时间。在这种计算里，时间圈的长度设定温度：时间圈越短，宇宙越热。所以交换两个圈，就把冷宇宙换成了热宇宙。这两种解释对应霍金和佩奇研究的那两个竞争历史。三维引力里没有引力子，但有类似的相变。

关键一步来了。在相对论里，空间和时间是平权的，所以哪个圈叫空间、哪个圈叫时间不应该有物理差别。对相对论来说，两种解释等价，任何实验的物理结果都必须一样。但量子力学对时间和空间的处理不同。要计算任何东西，你必须选一个方向叫时间，然后追踪系统沿这个方向演化。所以当我们计算量子引力中的可观测量时，甜甜圈的两种解释会导致看起来很不一样的计算。可相对论又要求，哪个圈叫时间不重要，所以两种计算必须给出完全相同的结果。如果我们知道三维量子引力理论，我们可以两边都算，再确认它们匹配。我们不知道理论，但自举法说没关系。物理学家扫描 c 和 M 一，对每一组值，试图证明这个理论会自相矛盾，也就是甜甜圈上的两种计算不可能给出相同答案。这需要寻找一个特殊数学对象，叫自举泛函。如果找到了，理论就不一致，这组值就被排除。

自举法在其他问题上的成功给了希望：把它和其他方法结合，最终能排除三维量子引力的绝大多数可能理论。剩下的理论就是同时兼容引力和量子力学的理论。物理学家就可以用它们探索量子引力的大问题：是不是只有一个理论？它是否依赖弦论，还是有别的可能？黑洞在微观上由什么组成？时空历史求和到底怎么做？这个策略原则上可行，但实践上很难，因为自举泛函很难找。对量子引力真正重要的是 c 很大时会发生什么，可 c 越大，搜索越难。在海勒曼最初的模自举论文里，他证明任何一致的三维引力理论中，M 一不能大于 c 除以六，加上一些小修正。最轻黑洞更重的理论，不可能同时兼容引力和量子力学。

模自举法的目标，就是把这个上限压得尽可能低，钉住最轻黑洞能有多重。物理学家把上限写成 M 一小于等于 c 除以拉姆达。上限越低，拉姆达越大。文章下面讨论的结果，包括 Claude 的结果，都是针对这个最简单、研究最多的版本，忽略黑洞自旋。过去十五年，物理学家一直在压低上限。有两条路：一条是解析的，用纸笔数学手工构造自举泛函；另一条是数值的，用计算机搜索泛函并优化。数值计算暗示，模自举法可以把上限压到大约 c 除以九点一。但这些计算随着 c 增大越来越难，所以不能定论。解析方面，哈特曼、马扎奇和拉斯特利证明了一个 c 除以八点五的上限，但这比数值暗示的高，显然不是模自举法能做到的最好。从那以后，模自举法到底能多紧地约束量子引力，一直是个开放问题。

Claude 的做法是先跑数值实验，复现文献结果。在这个过程中，它注意到一个物理学家此前漏掉的模式，涉及数值上限随着 c 增大而轻微移动的方式。基于这个模式，Claude 提出一个关于自举泛函行为的假设，用到一个叫谱曲线的数学工具。谱曲线在数学和物理的其他领域很有名，但从未被用到这个问题上。Claude 找到了支配大 c 时模自举法的谱曲线，然后用它证明三维量子引力中最轻黑洞的质量不能超过 c 除以拉姆达，拉姆达由一个精确公式给出，大约是九点一二六六。它还证明这个上限是最优的：这个版本的模自举法不可能再压得更低。Claude 把解法写成四份研究笔记，后来合并成一篇论文。

这是自举法第一次在黑洞起作用的量子引力区域推出精确结果之一。它也说明，这个版本的方法本身不能把上限压到 c 除以十二，也就是黑洞刚开始出现的质量尺度；那需要其他 ingredients。虽然它没有单独钉死三维量子引力的理论，但它提供了一个起点，帮助缩小搜索范围。

文章还专门讲了 Claude 的方法。二〇二六年八月，Anthropic 的研究员陈宏斌在做一个副项目，测试 Claude 的能力。他让 Claude 列出理论物理中有趣的开放问题，特别关注黑洞和自举法。几个小时后，Claude 带回二十二个候选问题。陈宏斌为每个问题建立独立智能体，它们可以读彼此的进度帖，在相关问题上有协作。智能体在后台运行，没有特殊设置，大约六周。最后解决了这篇文章里的两个问题。一个是霍金—佩奇相变，热气体什么时候变成黑洞。一个智能体得到解法几周后，一位独立用 Claude 研究同一问题的物理学家分享了他的结果，同事发现陈宏斌的智能体更早得到同样答案。两个解法用了不同方法，所以互相成了有用的检查。模自举法的结果来自几个智能体。被分配这个问题的智能体在浏览文献时发现了数值结果里的模式，另一个正在研究高维空间里球体最密堆积问题的智能体，把这个模式变成了方法。它发现这个方法复现了一个由 OpenAI 模型最近证明的球堆积结果。Claude 随后把同样方法用到自举问题上，而早先一个 Claude 智能体曾经尝试过并失败，做了六十一次并行尝试。另外两个智能体也独立得到同样答案。最终证明的一半，也就是证明上限不能再降低的那一半，遵循了 OpenAI 证明的策略。九月，结果在 Lean 这个计算机证明检查器里形式化验证。然后 Claude 在很少指导下写出论文，一位物理学家检查了每一个主要结果。

现在来到实践应用。你可能会问，这跟我们做软件、做 AI 产品有什么关系？我不建议你明天就跟老板说我们要去解量子引力。但这里面有几个可以迁移的工程模式。第一，长周期后台智能体。文章里的智能体不是一次 prompt 就结束，而是在后台跑了大约六周，能读彼此进度，能协作。这对做大型重构、长链路研究、复杂数据分析有启发：把任务拆成可并行的子问题，让智能体持续工作，定期写进度帖，而不是每件事都等人盯着。第二，独立重复计算。Claude 几乎每个计算片段都让两个智能体独立做，再对比。这在工程上就像关键路径双人复核，或者用两套实现跑同一组测试。对 AI 生成代码尤其重要，因为模型会自信地犯错。第三，跨领域类比。第二个问题里，球堆积问题的智能体把方法带到了自举法。这提示我们，做 RAG 或者研究助手时，不要只在一个领域文献里搜，可以让不同背景的智能体互相看笔记。第四，形式化验证。Lean 检查的是证明的形式正确性，不等于物理意义一定对，但它能把“算错了”这类错误挡住。工程里对应的就是类型系统、单元测试、属性测试、SMT 求解、模型检查。越是长链路自动生成，越需要机器可检查的约束。第五，人类专家复核。文章明确说，物理学家检查了每一个主要结果。这一点不能省。智能体可以扩大搜索空间，但问题的定义、结果的解释、物理意义的判断，仍然要人来做。

要避的坑也很清楚。第一，不要把“智能体跑了很多次”当成正确性证据。六十一次并行失败之后成功，说明搜索策略和跨领域迁移起了作用，不说明多数投票一定对。第二，注意验证的边界。Lean 验证的是形式化陈述和证明，如果陈述本身编码错了，或者物理假设没被形式化，检查器不会替你发现。第三，注意成本和可复现性。六周后台运行、多个副本、独立复算，这些都是计算资源。做团队落地时，要设计预算、日志、中间产物和失败回收，不然很容易变成昂贵的黑箱。第四，警惕叙事膨胀。两个结果都没有直接描述我们的宇宙，也没有现实应用。它们是理论物理长期努力的一部分，不是量子引力已被解决。第五，问题选择比解题更重要。陈宏斌先让 Claude 列二十二个候选，再分派智能体。这个“选题”环节仍然高度依赖人的品味和领域判断。

我个人认为，这篇文章最值得注意的不是“AI 又解了两个题”，而是它展示了一种可复制的科研协作结构：人类提出方向和验收标准，智能体做长周期搜索和计算，独立副本做交叉验证，形式化工具做机器检查，专家做最终解释。这个结构对软件工程里的复杂迁移、性能优化、安全审计也有借鉴意义。当然，它也有明显的局限：目前只在少数适合计算和形式化的领域里表现突出，换成需要实验、需要 tacit knowledge 的问题，方法未必成立。

收尾总结一下。Claude Fable 5.2 这次做了两件不同的事：一件是把二〇〇三年搭好的霍金—佩奇相变计算真正算完，证明弱耦合下也是突然相变，和引力侧对应；另一件是在模自举法里发现数值模式，引入谱曲线，证明最轻黑洞质量上限约为 c 除以九点一二六六，并证明这个上限已最优。两个结果都经过 Lean 验证和物理学家检查，但都不直接描述真实宇宙，也没有工程应用。我的点评是：这是一次很有分量的 AI for science 演示，价值在于研究工作流，而不在于马上改变产品；对 AI 从业者来说，值得学的是独立复算、跨领域迁移、形式化验证和人类把关这套组合拳。
