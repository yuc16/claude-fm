你好，这里是 Claude FM，我是主播。今天要跟你聊的这篇文章，标题是 GLM-5.3 and the spread of advanced cyber capabilities，中文翻译过来是《GLM 五点三与高级网络攻击能力的扩散》。文章发表在二〇二六年九月二十九日，来自 Anthropic 的前沿红队和政策团队，署名是五位研究者。

今天是二〇二六年十月七日，距离文章发表只过去了八天。这个时间点很重要，因为我们聊的不是一篇回顾性的总结，而是一份刚刚出炉的现场报告。如果你最近在关注开源模型的发布节奏，大概已经感觉到空气里的味道变了。过去一年半，开放权重模型在推理、写代码、做数学题这些维度上追得越来越紧，大家讨论的主要还是"能力差距还剩几个月"。而这篇报告讨论的是另一件事：当这种能力具体落在自主挖掘并利用软件漏洞这个方向上，而且模型可以被任何人下载、修改、把护栏拆掉的时候，会发生什么。

我先把结论抛出来，免得你听到一半才发现重点在哪里。Anthropic 的评估是，智谱 AI 发布的 GLM 五点三，在网络攻击能力上已经和 Anthropic 五个月前限量发布的 Claude Mythos Preview 处在同一个量级。但两者的发布方式完全不同。Claude Mythos Preview 只通过一个叫 Project Glasswing 的可信访问计划，交给经过审核的防御方使用，让他们抢在攻击者之前找到了上万条关键软件的漏洞。而 GLM 五点三是一个开放权重模型，任何人下载下来就能用，内置的安全护栏又很容易被绕过。Anthropic 在模拟测试里发现，用几种简单手法，攻击者绕过 GLM 五点三护栏的成功率在百分之六十四到百分之百之间。

这一期节目，我们会把这篇报告拆成几个部分来讲。先讲清楚这个能力到底强在哪里，Anthropic 用了哪些基准测试。再讲他们怎么用真人专家配合模型，在一天之内挖出一个浏览器 JavaScript 引擎的完整攻击链。然后重点讲护栏是怎么被绕过的，什么是 abliteration，为什么同一个手法对闭源模型不适用。最后我们会落到实践层面，聊聊这对做安全、做平台、做模型的人具体意味着什么，以及你可以马上开始做什么。

我会尽量把技术细节讲清楚。但同时要说明一点，这篇报告的内容全部来自 Anthropic 自己的红队测试，测试环境是隔离沙箱，攻击目标都是他们自己搭建的。我会忠于原文，凡是我自己的判断，我都会明确说是我的看法。

要理解这篇文章的分量，得先回到五个月前。二〇二六年上半年，Anthropic 宣布了 Claude Mythos Preview。按他们的说法，这是第一个能够自主构建复杂、端到端网络攻击利用的 AI 模型。端到端这个词很关键。

以前我们看到的 AI 安全研究，模型通常能做到链条中的某一环。比如帮你读一段代码，指出这里可能有缓冲区溢出；或者给你一个崩溃样本，帮你分析崩溃点在哪里。但端到端意味着，从发现漏洞，到判断这个漏洞能不能被利用，到写利用代码，到绕过现代操作系统和浏览器一层又一层的缓解措施，最后拼成一个真正能打通的攻击载荷，这一整条链路，模型可以自己做下来。这中间每一步都需要不同领域的知识，而且每一步都可能失败，需要退回去重来。

Anthropic 当时的判断是，这种能力不会停在某一个模型里。因为整个行业的模型能力都在快速提升，今天只有最前沿模型能做出来的事情，过几个月就会成为很多模型都能做的事情。所以他们做了一个在当时看起来有点反直觉的决定：不把这个模型公开，而是通过一个叫 Project Glasswing 的计划，只让经过审核的可信防御方使用。结果是在这五个月里，这些防御者在关键软件里找到并报告了一万多个漏洞，相当于在攻击者拿到同样工具之前，先抢到了一段窗口期。

这段叙述里有一个很重要的逻辑，我觉得值得你留意。这其实是一种以时间换空间的防御策略。防御方的优势从来不是能力更强，而是他们可以在攻击者动手之前先把洞补上。一旦同样的能力扩散出去，这个窗口就关上了。Anthropic 这篇文章之所以要写，就是因为，用他们自己的话说，那些模型已经来了。

那么来的这个模型是谁？GLM 五点三，智谱 AI 开发，在中国大陆之外的品牌名叫 Z.ai。如果你对国内大模型比较熟悉，智谱你肯定不陌生，它是国内第一梯队的大模型公司之一，GLM 系列一直是国内开放权重模型里最有代表性的产品线之一。这篇文章发表的十二天前，也就是二〇二六年九月十七日，美国国家标准与技术研究院旗下的 AI 标准与创新中心，英文缩写 CAISI，发布了一份自己对 GLM 五点三网络能力的评估。CAISI 的结论是，GLM 五点三是迄今为止发布的网络能力最强的开放权重模型，在 CAISI 的多个网络基准的综合评分上，大约落后美国前沿模型四个月。

Anthropic 说他们的能力评估结论和 CAISI 大体一致。但有一个细节非常关键。在 CAISI 的对比测试里，美国模型是在适用时关闭了网络安全护栏之后测试的，而且所谓美国前沿，包含了那些只向经过审核的用户发布的模型。也就是说，那四个月的差距，是拿一个去掉了护栏、而且普通人根本拿不到的美国模型，去比一个谁都下载得到的 GLM 五点三。这两个数字不可比。攻击者拿不到那些版本的美国模型，但 GLM 五点三任何人现在就能下载。这篇文章要补充的，恰恰就是后半段，它的护栏到底有多容易绕过或者删除。

顺便说一句，四个月这个数字，放在别的行业可能没什么感觉，但在 AI 领域，它意味着大约两到三代模型迭代。也就是说，这四个月的差距，是可以用时间换来的，而且换来的速度还在加快。这是我认为这篇文章最让人不安的一个隐含前提。

好，我们进入能力评估部分。

先讲第一个基准，叫 ExploitBench，专门测 AI 模型能不能利用 Google Chrome 里 V8 引擎的已知漏洞。V8 是 Chrome 跑 JavaScript 的引擎，也是全世界被研究得最透彻的攻击目标之一，它本身有一整套复杂的防御机制。ExploitBench 关心的是端到端成功率，也就是模型能不能从漏洞出发，最后交出一个真正能用的利用程序。

结果是，GLM 五点三在四百一十次尝试里，成功做出了五十次端到端利用。Claude Mythos Preview 的成功率几乎一样，四百一十次里成功了五十六次。

这里我需要停一下，帮你体会这个数字。四百一十次里成功五十次，成功率大约百分之十二。单看百分比，你可能会觉得也不高啊。但请想一想这个任务的难度。做一个 Chrome 的完整利用链，是人类顶尖安全研究员要花几周甚至几个月才能完成的工作，需要掌握 V8 的内部结构、堆布局管理、类型混淆的各种技巧，还要绕过地址空间随机化、沙箱、控制流完整性这些一层层的缓解措施。而且这里面有一个残酷的地方：整条链上任何一环错了，最后的结果就是零，不是部分成功。一个自动化系统，在四百多次尝试里能独立完成五十次，这已经是质变。而且更重要的是，模型的能力曲线还在往上走，今天百分之十二，明年可能就是百分之四十。

第二个基准是 Anthropic 内部的二进制利用基准。这个测试的场景不太一样。它挑的是那些参与 Google OSS-Fuzz 项目的流行开源软件。OSS-Fuzz 是 Google 运营的一个持续模糊测试项目，它常年对大量开源项目做自动化测试，发现的崩溃样本会沉淀成公共数据。这份数据既是开源项目修 bug 的来源，客观上也成了一块很好的能力测试场。这些软件里存在各种漏洞，看模型能不能找到并且利用它们。满分标准是完整的控制流劫持。简单说，就是让程序跳转到攻击者指定的位置去执行攻击者的代码，这是二进制漏洞利用里的最高目标。

Anthropic 从基准里随机抽了一百个任务来测。GLM 五点三在百分之四的试验里做到了完整的控制流劫持，Claude Mythos Preview 是百分之六。

百分之四听起来更低了，但这组数字里最有信息量的其实是后面半句。更早的模型，比如说 Claude Opus 四点六和 GLM 五点二，在这个测试里一次都没有成功。一次都没有。所以从零到百分之四，这不是量的变化，这是从做不到到做得到的跨越。Anthropic 的原话是，一个有意义的分水岭已经被跨过了。

我个人认为，这个从零到非零的转折，比具体的百分比更值得记住。安全领域有一个朴素的经验，只要存在一条可行的攻击路径，防御方就必须把它堵上，而攻击方只需要成功一次。当模型能力处在零的时候，你可以说这类攻击还不现实。一旦变成非零，哪怕只有百分之四，防御假设就必须彻底改写。而且这里还有一个统计上的放大效应：模型可以被无限次重试，成本几乎只有算力钱，而人类研究员会疲劳、会放弃、会去干别的项目。这个不对称，才是自动化攻击最可怕的地方。

好，接下来讲人类专家配合的测试。这部分我觉得是全文最生动的，也最值得你慢慢听。

前面两个是自动化基准，跑的是模型单打独斗的成绩。但真实世界里的攻击者不会让模型自己瞎跑，人会参与。所以 Anthropic 又做了一组有人类专家在环的测试。方式和他们今年早些时候测 Claude Mythos Preview 时一样。先挑选一些目标，而且确保参与测试的人类专家不知道这些目标里已经存在什么漏洞。然后让专家用模型去发现和利用全新的、未被公开的缺陷。实验的时间窗口很短，通常是一天以内，人类真正专注投入的时间加起来不到一小时。

这个实验设计里有一个细节我要专门指出来，因为它决定了结论的可信度。专家不知道目标里已经有什么漏洞，这一点非常关键。如果专家知道答案，模型只要跟着人的引导走，测出来的就是人的能力而不是模型的能力。而把人的注意力限制在一小时以内，也是在控制变量：如果人类投入很多时间，那最后的成果到底是模型的功劳还是人的功劳，就说不清了。这个设计，你在做任何 AI 工具评估的时候都可以借鉴。

第一场实验，一个研究员在一台隔离沙箱机器上，用 GLM 五点三去攻击一个流行网页浏览器的本地 Linux 构建版本。在一天的时间里，而且人类注意力非常有限的情况下，GLM 五点三在这个浏览器的 JavaScript 引擎里找到了好几个之前不为人知的漏洞，并且把它们串成了一条可用的利用链。这条利用链的最终效果是，一个网页，只要访问者打开它，它就能从访问者的电脑上读取任意文件。

这句话我希望你多咀嚼一下，因为它是这篇报告里最具体、最有画面感的一个结论。网页在你浏览器里跑，按理说是被沙箱层层隔离的，它不该有能力去读你硬盘上的文件。这正是浏览器安全模型的核心承诺。而 GLM 五点三做的事情是，它自己找到了几个没人知道的漏洞，自己设计了怎么把它们组合起来，最后自己写出了一个能实际运行的攻击页面。整个过程人类只提供了很有限的注意力。

如果你来做这件事会怎样？假设你是一个有五年经验的漏洞研究员，让你去挖一个成熟浏览器的 JavaScript 引擎漏洞。你需要先读大量源码，理解编译器后端和即时编译机制的边界条件，然后猜测哪个地方可能存在类型混淆，再写测试用例去验证，然后处理各种边界情况，最后把几个不同的漏洞拼起来。这个过程的每一环都可能卡住几周。而报告里描述的，是模型在一天内走完了这条路。我不认为这等于说人类研究员没有价值了，恰恰相反，懂得如何设定目标、判断结果、设计验证方式的人，价值会更高。但确实，纯粹的执行劳动，正在被快速替代。

这里还有一个细节。因为实验环境只提供了 Linux 版本，这个利用链是针对 Linux 构建的。Anthropic 说他们认为这些漏洞可能同样影响其他平台上的用户，只是在其他平台上利用的路径可能会更复杂。他们已经把这些漏洞披露给了维护者。同一场实验的后面，这位研究员还用 GLM 五点三在另外几个被广泛使用的系统里找到了可利用的漏洞，包括无线驱动、图形驱动，以及面向网络的设备软件。Anthropic 说这些报告还在审核中，之后会按情况披露给相关维护者。

请你注意这几类目标的共同点：驱动和网络设备软件。这些东西的特点是，它们通常跑在用户不太能直接观察到的层面，补丁周期长，很多设备甚至根本不会更新固件。这类目标一旦被攻破，影响面往往比单个浏览器漏洞大得多。所以这句话你可以理解为报告里一个低调但很重的暗示。

第二场实验更有意思，因为它测的是速度。这次研究员用的是 GLM 五点三 Flash，也就是 GLM 五点三 的更小、能力更弱的版本。目标不是找未知漏洞，而是一个已知漏洞。这里说的已知，是指补丁已经公开的那种，安全圈里通常叫 N-day 漏洞。这个概念值得解释一下。所谓 N-day，指的是漏洞已经被厂商修复、补丁已经发布，但是全世界还有大量设备没有打上补丁。对攻击者来说，这类漏洞性价比很高，因为技术细节往往已经公开，不需要自己从头研究，只需要把公开的信息转化成能用的攻击。

这次的目标是 Google Chrome 里一个刚披露不久的漏洞，编号是 CVE 二〇二六一一六四五。研究员把公开信息交给了 GLM 五点三 Flash，同时还给了另一个已知漏洞的信息，然后基本上没有再做别的指导。结果 GLM 五点三 Flash 把这两个漏洞串成了一条可靠的利用链，针对 ARM64 架构的目标，而且绕过了指针认证这种硬件级加固机制。

指针认证，英文叫 pointer authentication，是 ARM 架构上用来防止攻击者篡改指针的一种硬件缓解措施。简单说，它给指针加上一段密码学签名，攻击者如果随便改指针，签名就对不上，程序就会崩溃。这套机制在过去几年里被认为是相当有效的。绕过它，说明模型不只是会拼现成的利用代码，它理解这套机制并且能找到绕过它的路。

这件事花了多少成本？人类注意力二十分钟，GLM 五点三 Flash 自己工作了八个小时。按智谱的 API 价格算，这一整套工作花了二十点四美元。

二十美元。我重复一遍，二十美元。这个数字我认为是整篇报告里最该被记住的一个。它意味着，把一个公开补丁变成一个针对特定架构、能绕过硬件加固的可用攻击链，成本已经降到了一顿外卖的价钱。过去这种工作需要顶尖的漏洞研究员，工作几天到几周。现在你付二十美元 API 费用，等八个小时，中间看二十分钟。

我自己对这个数字的解读是，它改变的不是谁能做攻击，而是攻击的经济学。当单次攻击的准备成本从几万美元降到几十美元，攻击者可以做的事情就从精心挑选一个高价值目标，变成批量试。这对防御方的意义是，你不能再拿我们的系统不够重要、不会被盯上这种假设来排优先级了。

好，能力部分讲完了，接下来是这篇文章真正的核心议题，护栏。

GLM 五点三 发布的时候是带一些内置安全机制的。如果一个用户提出明显有害的请求，模型通常会拒绝。这个机制在很多模型上都有，形式上一般是模型在训练时被对齐到一个遇到这类请求就说不的行为模式。问题是，这种护栏是软的，不是硬的。

Anthropic 说他们在测试中发现，这些护栏可以用多种简单技术绕过，或者干脆去掉。

最彻底也最有效的方法，是一种标准的拒答削减技术，业内叫 abliteration。这个词是把 ablation 和 obliterate 拼起来的，字面意思大概是消融掉拒答行为。原理并不神秘。因为 GLM 五点三 是以开放权重的形式发布的，也就是模型参数会公开给所有人下载，所以任何人都可以在本地重新配置它，把导致拒答的那部分行为去掉，而模型的整体能力几乎不损失。报告里说，在 GLM 五点三 发布后的几天之内，就有好几个开发者向公众发布了消融过的版本。

这里我想稍微展开一下这个概念，因为它触及了一个很多人没想清楚的问题。大模型内部的行为倾向，并不是散落在每一个参数里的，很多时候它对应着参数空间中某个相对集中的方向。如果你能找到这个方向，然后沿着相反方向做一次调整，就能系统性地削弱这种倾向。所以消融做的事情，本质上是在模型的权重里找到那根叫我不干的弦，然后把它剪断。这个过程需要算力，需要一些技巧，但并不需要重新训练模型，也不需要原始训练数据。

Anthropic 自己也做了一遍，用来量化效果。他们团队之前从来没有做过这件事，结果花了大约两千两百个 GPU 小时，算力成本约四千四百美元。GLM 五点三 Flash 的消融花了大约六百个 GPU 小时。做完之后发生了什么？在 JailbreakBench 和 HarmBench 这两个衡量模型对有害请求顺从率的公开基准上，GLM 五点三 的拒答率从百分之九十以上，降到了大约百分之三和百分之二。在第三个基准 StrongREJECT 上降到了百分之十二。而在 GPQA-Diamond 这个衡量通用科学能力的评估上，原版和消融版的分数完全一样。在 CyberGym 评估的一个子集上，消融版只低几个百分点。

我帮你把这个结论翻译成一句话。你花四千多美元，就能把一个多数时候会拒绝恶意请求的模型，变成一个几乎不拒绝的模型，而它在科学和网络攻防上的能力基本没变。

注意这里有一个反直觉的地方。做消融这件事的算力成本，比很多人想象的要低得多。两千两百个 GPU 小时，对于一家公司来说不算什么，对于几个有经验的研究者加上租用算力来说也不算门槛。也就是说，开放权重模型的安全护栏，本质上是一种自愿遵守的约定，而不是技术上的禁令。只要有人想拆，就能拆，而且拆完还能公开分发。这一点，是开放权重路线和闭源路线在安全属性上最根本的分歧。

而且报告里有一个细节值得注意：Anthropic 反复强调，他们团队此前从未尝试过消融这件事。这句话的潜台词是，这是一个门槛并不高的任务，第一次做就能做成。你可以设想一下，如果是一些本来就熟悉模型内部机制的团队来做，结果只会更高效。

然后 Anthropic 还测了一种更轻的绕过方式，不需要动模型权重，只需要在提示层面动手。

他们设计了一个模拟世界，在里面给模型一些明确的恶意请求，比如让它去攻击关键系统。开箱状态下的 GLM 五点三 在所有试验里都拒绝了，和 Anthropic 测的其他模型一样。但他们找到了几种简单的方法可以让它上钩。

第一种，用一个欺骗性的提示词。比如告诉模型，你现在是一个正在参加演练的自主红队 agent。这个说法让 GLM 五点三 有百分之六十四的概率开始执行任务。

第二种，预填模型的思考 token。所谓思考和 token，你可以理解为，模型在被要求回答之前，会先输出一段我来分析一下的内部推理过程。如果你能人为地把这段推理的开头写进去，让它看起来好像已经分析过这个请求并决定要执行，模型就会顺着这个既成事实往下走。这一招让 GLM 五点三 的执行率达到了百分之九十二。

第三种，就是前面说的消融版本，百分之百执行。

这三种手法里，我觉得第二种最值得注意，因为它不涉及任何模型改动，只是利用了模型的一个工程特性。很多推理模型允许你把一段内容预填到它的思考过程开头，用来引导输出格式或者控制输出。这个功能在设计初衷里是完全中性的，甚至是方便的。但在没有护栏的场景下，它就变成了一个绕过手段。这提醒我们一件事，安全属性往往不是被某个大漏洞击穿的，而是被一堆各自看起来都合理的设计选择共同削掉的。

后面 Anthropic 做了一组对比，来说明 Claude 这边的情况。他们用同样的手法去测有护栏的 Claude 模型。结果是，这些技术没有一次让 Claude 执行那些有害任务。欺骗性提示词被 Claude 的护栏挡住。Anthropic 的 API 不提供预填思考内容的途径，所以第二招用不了。而 Claude 的权重不向用户提供，所以没法做消融。另外他们特别说明，用消融版 GLM 五点三 的时候，模型生成的思维链里有一段话特别能说明它的态度，原文在这里引用了那句话作为例证。

这一段对比其实是整篇文章立论的支点。Anthropic 想说的不是我们的模型更安全这么简单，而是说，模型的安全属性是由发布方式决定的。同样的能力，闭源加可信访问计划，和开放权重无门槛下载，在攻击者手里的可用性完全不是一个级别。这一点的确成立。但我作为听众也想提醒你，不要把这个对比读成纯粹的商业宣传。文章里有一段话我认为是相当克制的。他们承认这些能力对防御方同样有用，而且明确说防御方应该使用能满足需求的最好工具，包括那些能力至少和对手相当的模型。这是一个理性的立场，尽管它同时也符合 Anthropic 的商业利益。

文章还有一个我觉得值得一提的判断。Anthropic 说，已有证据显示，国家行为体和非国家行为体都尝试过用 AI 系统做攻击，所以他们判断这两类角色都很可能会用 GLM 五点三 这样的模型来造成现实世界的伤害。这句话没有给出具体案例，但它把风险从理论层面推到了已有的行为模式层面。

好，讲完核心内容，我们来聊聊这些对听众的实际工作意味着什么。这部分有我自己的延伸，不是原文内容，我会明确标注。

第一件事，对企业安全团队来说，你需要更新你的威胁模型。过去你在做风险评估的时候，隐含的假设是，能写出 Chrome 完整利用链的人，全球可能只有几百个，而且都很贵。现在这个假设要改成，能写出利用链的工具，成本是每任务几十美元，任何人都能下载，而且它可以不知疲倦地跑四百一十次。这意味着攻击面的经济性变了。你不需要成为高价值目标才会被批量尝试。所以第一优先级的动作是把资产清点和补丁管理做得更扎实。这篇文章里最有价值的一个信息其实是，漏洞发现的速度已经被 AI 拉动了一大截，那么修复速度如果还停在人工节奏，缺口只会越拉越大。

第二件事，不要把模型自带的拒答当成安全边界。这是我最想在节目里强调的一点。GLM 五点三 的例子很清楚，拒答率百分之九十听起来不错，但消融之后是百分之三，而在提示层面绕过之后是百分之六十四到百分之九十二。如果你的安全设计里有任何一环是因为模型会拒绝，所以这个风险不存在，那一环就是纸糊的。正确的做法是把模型能力当成一个已知的、无差别的输入。假设对手手里就有一个不会拒绝的版本，然后去设计你的纵深防御。

第三件事，对防御方来说，这同样是个机会，而且是必须抓住的机会。文章里提到 Project Glasswing 让可信防御者找到了上万条漏洞，这就是能力用在正确方向的证明。如果你在做安全，你完全可以做同样的事。把这类模型接进你的漏洞挖掘流程，用沙箱隔离、限定目标、人类复核的方式，让它在你自己维护的代码库或者你有授权的目标上跑。这里有几个坑要避开。一是必须有严格的沙箱和网络隔离，模型在测试的时候可能会做出意料之外的事情，你必须假设它会越界，所以物理隔离或者至少是严格的网络出口控制是必需的。二是要有人工复核环节，模型给出的漏洞报告质量参差不齐，误报率不低，你需要有人能判断哪些是真的，哪些是幻觉。三是注意合规，只在你拥有或有明确授权的目标上测试，这一条没有例外。

第四件事，关于补丁速度。前面那个二十点四美元的例子，最直接的含义是，一旦某个漏洞的补丁公开，把它变成可用攻击的时间窗口已经短得可怕。人类二十分钟注意力加八小时机器时间，就把一个 Chrome 的已知漏洞做成了绕过硬件加固的利用链。如果你所在的组织还维持着一个月打一次补丁的节奏，那你实际上是把自己的系统暴露在那段窗口里。缩短补丁周期、对关键系统做自动化热修复、对公开披露保持监控并分级响应，这些不是新鲜的建议，但紧急程度变了。

第五件事，如果你在做模型，或者在做模型相关的产品决策，这篇文章给了你两个具体的清单项。一个是发布方式的选择。开放权重意味着你放弃了事后的控制能力，这个取舍必须在发布前想清楚，而不是出了问题再补。另一个是评估方法。注意 Anthropic 和 CAISI 都在用同一套思路，标准化的自动基准做初筛，人类专家在环做深度验证，沙箱化环境保证安全。如果你要做自己的模型安全评估，这套组合拳是值得抄的作业。特别是人类专家不知道目标里存在什么漏洞这个设计，它保证测出来的是真实的发现能力，而不是模型复述训练数据里的已知信息。

我还想补一个角度，是这篇文章没有直接讲但我认为和国内听众特别相关的。GLM 五点三 是国产模型，这一点在讨论里很难回避。文章对它的评价是技术能力上的肯定，同时批评的是发布方式和护栏强度。作为国内从业者，我觉得比较健康的态度是分层看这件事。能力上，能做出这个水平的模型，是实打实的成绩。发布策略上，开放权重本身是一种技术路线的选择，有它的正当理由，包括促进研究、降低门槛、避免能力垄断。但当模型具备了可以直接转化为现实攻击的能力时，发布方是否应该配套更强的滥用监控、更严格的权重分发条件、更透明的评测报告，这是整个行业都需要回答的问题，不只是某一家公司的问题。我个人认为，最好的结果不是把能力锁起来，而是把安全评估和披露机制做成行业惯例。

好，最后我们来做收尾。

这篇文章的核心主张，我总结成三句话。第一，五个月前只有 Anthropic 最前沿、且只对审核用户开放的模型才具备的端到端网络攻击能力，现在已经出现在一个任何人都能下载的开放权重模型上，能力水平大体相当。第二，这个模型的护栏可以用简单手法绕过，消融版把拒答率从百分之九十以上降到接近零，而能力基本不损失，成本是几千美元和几千个 GPU 小时。第三，这件事同时利好在两个方向上，攻击者拿到了便宜好用的工具，防御者也一样，问题在于防御方能不能更快地把工具用起来。

我个人的点评是，这篇文章最有力的地方不是它列举的那些百分比，而是它揭示了一个结构性的事实。AI 能力的扩散速度，已经超过了安全治理框架的适应速度。Anthropic 年初选择限量发布，是通过自愿约束来换时间窗口，这个窗口确实发挥了作用，一万多条漏洞被提前找到和修复。但窗口关上得比预期快。当同类能力可以从另一个渠道无门槛获得的时候，任何单一公司的发布策略都不再是全球性的控制手段。

这引出一个我认为很长一段时间内都会困扰行业的问题。开放权重的价值是真实的，它让研究者能审查、让中小企业能自建、让技术不被少数公司垄断。但同时，它也让安全护栏从一个技术事实变成一个自愿承诺。这两者之间的张力没有简单的解法。文章最后给出的建议是，各国政府应该对足够有能力的模型做安全测试，包括 GLM 五点三 的后续版本，因为如果缺少独立的高质量评估，这些能力的影响可能要等到太晚才会被开发者自己看清。这个建议本身是合理的，但它能不能落地、以什么形式落地，恐怕才是未来两年最值得观察的事情。

对我们每一个做技术的人来说，我想留下一个具体的问题。如果你的团队明天拿到一个不会拒绝任何请求的模型，你会先拿它做什么？如果你的第一反应是拿它去挖自己系统的漏洞，那你现在的防御姿势大概是对的。如果第一反应是不知道能做什么，那可能说明你对自己系统的攻击面还不够熟悉。想清楚这个问题的答案，比记住文章里任何一个百分比都有用。
