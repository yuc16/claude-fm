大家好，欢迎收听 Claude FM。这是 Anthropic 一周快讯，今天是二零二六年十月二十五号。本期我们回顾十月十八号到十月二十四号这一周，一共四条消息，涉及公共利益基金、治理层人事、Agent Skills 开放标准，以及生命科学研究合作。

先看十月十八号，Anthropic 宣布设立一家全资持有的公共利益基金实体，计划在股东批准后，将公司百分之五的股份投入其中。它还设计了追加机制：公司价值相对设定基准，每增长百分之五十，董事会可以酌情再投入百分之二的股份。

这项安排值得注意的地方，是它试图把公益投入和公司价值增长挂钩。按照公告，基金未来可能探索向传统公益机构大额捐赠，或者向特定人群直接发放资金，但这些目前都只是可能的方向，不是已经落地的项目。

接下来是十月二十一号的人事消息。实验物理学家、哈佛大学前理学院院长 Christopher Stubbs，加入了 Anthropic 的长期利益信托。他的背景包括观测宇宙学、精密测量，以及为美国政府提供国家安全和军控方面的建议；近期也关注过 AI 辅助研究的可重复性问题。这为 Anthropic 围绕长期公共利益的治理，补充了一位有科研和政策经验的成员。

本周的重点消息，来自十月二十二号。Anthropic 宣布，将 Agent Skills 开放标准捐赠给 Linux 基金会旗下的 Agentic AI Foundation，也就是 AAIF。

先说 Agent Skills 是什么。你可以把一个 skill 理解成给 AI 智能体准备的任务资料包。它是一个文件夹，里面有一份名叫 SKILL 点 md 的说明文件，用来教智能体完成某类任务，或者理解某个专业领域，还可以附带需要的脚本和参考资料。

它针对的不是模型缺少一般知识，而是模型不一定知道具体业务应该怎么做。Anthropic 说，最初开发 Claude Code 时，他们就发现了这个问题：通用知识工作做得不错，但真实业务需要的操作流程，往往还得另外提供。Skills 就是把这类流程和知识整理成智能体能使用的形式。

根据这次公告，Skills 在二零二五年十月推出后，开发者很快就开始为其他工具编写加载支持。同年十二月，Anthropic 将它发布为开放标准。到这次公告时，已经有超过七十个智能体平台集成，包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code。官方给出的累计数据是，已发布一百万个 skills，安装量接近两亿八千万次。这里说的是安装次数，不是用户人数。

所以，这次变化主要不在功能，而在治理。Agent Skills 此前已经开放，现在是把标准交给一个中立的基金会，让社区参与后续方向，而不只是由 Anthropic 一家公司主导。Anthropic 此前也把 MCP 捐赠给了这个基金会。

我个人觉得，对开发者来说，这条最值得关注的是跨平台复用的方向：如果不同智能体都支持同一种任务资料格式，团队就有机会减少为每个平台重复整理流程的工作。当然，具体能不能顺畅复用，仍然要看各个平台的实际实现，不能把支持同一个标准，直接等同于运行效果完全一样。

最后一条，同样是十月二十二号。Anthropic 开始面向生命科学领域，公开征集访问研究合作项目。

这次主要面向高校、非营利机构和政府实验室的课题负责人及其团队。研究方向包括人类生物学中的因果问题、结构与计算分子生物学、药物化学、药物发现，以及临床科学。

合作周期预计是八到十二周。入选团队会直接和 Anthropic 研究人员一起，围绕一个具体问题开展工作，产出研究分析、工具或者其他有用成果。期间由 Anthropic 团队免费运行模型和配套系统。

这里有两个细节值得留意。第一，申请者需要说明，为什么直接与 Anthropic 研究人员合作会有帮助，也要合理解释，为什么预期成果能在八到十二周内做出来。也就是说，它不是泛泛征集一个宏大的研究方向，而是希望找到周期明确、能够交付具体成果的项目。

第二，公告提出，双方将合作发表成果，并开源配套数据和代码，同时研究者在整个项目期间保留自己的数据权利，也保留后续独立研究的权利。部分项目可能获得延期，但不是所有项目都有保证。

我个人觉得，这条消息值得关注的，不只是免费使用模型，而是 Anthropic 想通过直接参与真实科研问题，探索 Claude 在生命科学工作流里究竟能发挥什么作用。至于能带来哪些发现，还要等项目结果，不能把合作征集当成已经取得科研突破。
