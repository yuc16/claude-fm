## Script

哈喽，这里是 Claude FM 的 Anthropic 一周快讯。今天是九月二十号，我们回头来看九月十三号到九月十九号这一周，Anthropic 一共对外宣布了两件事，数量不多，但两条都挺有分量，一条关于模型能干什么，一条关于谁来监督它。

先看九月十七号。Anthropic 发布了一个叫生命科学验证计划的东西，英文是 Life Sciences Verification Program。它做的事情是，给生命科学领域的专业人士开放 Mythos、Opus、Sonnet 这几个模型，而且配了一套专门调过的防护策略，对生物相关的工作更宽松。为什么要单独开这么个口子？因为在 Anthropic 面向大众开放的那套 Fable 模型里，药物发现、研究生物学、临床开发、生产制造这些任务基本上是被挡住的，做这行的人拿通用模型几乎没法干活。这次等于开了一条受控通道，想进来要先过一道验证，审你的科研资历、你的安全标准、还有你的伦理研究监督机制。过了之后可以申请两种授权，一种叫标准用途，一种叫高风险用途，看你的实际需要。授权拿到手之后，包括 Claude Science、Claude 网页版、Claude Code 和 API 都能用。

这条我觉得值得多想一层。它的意义不在于多放开了几个功能，而在于把限制从一刀切改成了分级、可验证的准入。之前行业里处理敏感领域，通常就是简单封掉，代价是正经科研人员也被误伤。现在 Anthropic 试着用验证加分级授权来解决，早期已经有几十家机构在试用，现在开放申请，不过还是 beta 阶段，先面向团队和机构，个人的 Pro 和 Max 订阅以后再慢慢放开。对做生物医药的开发者来说，这是第一次能比较名正言顺地拿前沿模型干正事。我个人觉得，如果这套验证流程跑得通，它很可能会被复制到其他敏感领域去。

接下来第二条，是这一周分量更重的一条，九月十八号，Anthropic 宣布和埃森哲合作，做前沿 AI 的独立评估。具体由埃森哲旗下专门做 AI 的业务 Faculty 牵头，内容包括评估和红队测试模型、做对齐评估、测试模型的安全防护。两家公司各自预计在未来五年至少投入十亿美元。

这件事要放进脉络里看，它其实是 Anthropic 的 CEO 在那篇叫《我们必须放慢前沿》的文章里做过的承诺落地，也就是把评估者嵌入到公司内部。嵌入式评估是个新概念，和现在的外部评估很不一样。外部评估者基本只能在模型发布之后，从外面看结果。嵌入的评估者身份接近员工，能进到公司里面，能看到模型在训练过程中怎么一步步长出来，能追踪模型是怎么被构建、怎么被部署的这些决策，还能直接和员工对话。站在这位置上，他们可以判断这家公司实际是怎么运转的，有没有兑现自己的安全承诺，盲点在哪里，还能上报事故，给公众一个信息更充分的好处与风险说明。

Anthropic 自己也承认，嵌入式评估是新东西，很多操作细节还在摸索。但从行业角度看，这回答了「谁来评估前沿模型」这个问题的一种新可能：既不单纯靠监管，也不只靠外部第三方，而是让第三方住进公司里。它到底能不能保持真正的独立，是后面几年要盯的事。

好，这一周就这两条。一条是把模型准入做得更精细，一条是给安全治理试了个新机制。如果只挑一条记住，我会挑埃森哲这条，因为它动的不是某一款模型，而是整个行业怎么做独立评估的规矩。我们下周同一时间再见。
