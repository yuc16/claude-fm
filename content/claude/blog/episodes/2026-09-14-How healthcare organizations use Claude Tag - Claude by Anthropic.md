## Shownotes（复制到小宇宙）

Anthropic 官方博客在二〇二六年九月十四日放出了一篇医疗行业案例集，讲三家医疗科技公司怎么用 Slack 里的 Claude Tag 组建人机协作团队。最值得看的不是 agent 能干什么，而是他们把权限边界画在哪、怎么让人类专家留在环路里。

本期要点：

- Claude Tag 目前还没有被 Anthropic 的业务伙伴协议覆盖，所有案例团队都只把它放在永远不接触 PHI 的频道里
- 三层管控机制：默认关闭、逐个频道启用、私聊禁用，连接器按频道绑定，加上访问捆绑包把代码库和临床系统彻底隔开
- Insight Health 用双 agent 架构处理生产告警，一个看代码一个查生产数据，百分之九十七的关键告警无需工程师介入就关闭
- Tennr 让招聘和人力同事用自然语言提需求，Claude Tag 直接改代码、部署、上线，一个月交付十五个以上工单
- Medallion 让 Claude 回答付款方规则问题，不自信时主动 @ 专家，把专家回答沉淀成组织资产
- 自主权不是 agent 的属性，而是 agent 在特定频道里的属性，这句话是整个权限设计的骨架
