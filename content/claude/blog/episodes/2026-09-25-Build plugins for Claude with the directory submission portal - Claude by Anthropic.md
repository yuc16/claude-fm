## Shownotes（复制到小宇宙）

Anthropic 在二〇二六年九月二十五日上线了 Claude 插件目录的开发者提交门户，开发者可以提交插件、跟踪审核、自主决定发布时间，并在上线后查看安装与发现数据。这篇文章不长，但它把 Claude 生态里长期缺的一块拼图补上了——从"能连"到"有人用"。

本期要点：
- 插件是一个打包容器，把 MCP 连接器和 Agent Skill 装在一起，成为第三方扩展 Claude 的主要形态
- 两条提交路径：单个远程 MCP 连接器，或者托管在 GitHub 上的插件包；Claude Code 里还能带 LSP、命令、钩子和子智能体
- 门户提供自动验证与安全扫描、透明的审核状态和建议修改、以及开发者自己掌握的发布时机
- 上线后能看到按产品入口和版本拆分的安装量，以及列表查看次数和带来访问的搜索词
- Claude 支持带无状态核心的 MCP 二点零，并扩展了聊天内交互界面的 MCP Apps 和企业零手动授权的 Enterprise Managed Auth
- 已有的技能、连接器和插件无需改动，未来连接器列表可升级为插件，统一的发现体验即将在 Claude 和 Claude Code 推出
